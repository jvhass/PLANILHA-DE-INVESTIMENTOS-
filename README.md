# ⚡ INVEST+ — PERSONAL WEALTH COMMAND CENTER

Uma central pessoal de investimentos moderna, inteligente e prática para acompanhar minha carteira, patrimônio e evolução financeira.

## 💰 O que o INVEST+ faz

- 📊 Dashboard financeiro
- 💰 Patrimônio total
- 📈 Rentabilidade
- 🟢 Lucro e prejuízo
- 🏦 Controle de investimentos
- 💧 Acompanhamento de liquidez
- 📅 Controle de vencimentos
- 🎯 Metas patrimoniais
- 🧠 Análise automática da carteira
- ⭐ Health Score
- 📊 Gráficos
- 🧮 Simulador de investimentos
- 🔎 Pesquisa e filtros
- 📤 Exportação da carteira
- 💾 Salvamento automático no navegador

## 🧠 Assessora de investimentos

O sistema possui uma área de análise automática da carteira.

A ideia é acompanhar:

- concentração;
- diversificação;
- liquidez;
- rentabilidade;
- distribuição do patrimônio;
- vencimentos;
- evolução da carteira.

O sistema também apresenta alertas e insights para facilitar a tomada de decisão.

> O INVEST+ é uma ferramenta pessoal de organização e acompanhamento financeiro. Ele não substitui um assessor ou consultor financeiro profissional.
